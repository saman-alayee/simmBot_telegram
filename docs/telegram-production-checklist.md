# چک‌لیست تست نهایی تلگرام (بند ۱۵ سند bot test.docx)

پس از `npm run spec:compliance` (منطق + DB)، این موارد را **دستی** روی بات واقعی و کانال انجام دهید.

## ثبت و دوره
- [ ] ثبت خط جدید → موجودی + پست کانال
- [ ] همان شماره در حالت **موجود** → به‌روزرسانی همان دوره (نه دوره تکراری)
- [ ] خط **فروخته** → ثبت مجدد → `cycle` جدید + history دوره قبل
- [ ] مالک **پرظرفیت** در ثبت قابل انتخاب نباشد

## رزرو
- [ ] فقط خط **موجود** رزرو شود
- [ ] روی **همان پست** وضعیت رزرو + **Reply** «این خط رزرو شد»
- [ ] ادمین دوم نتواند همان خط را رزرو کند
- [ ] **فقط رزروکننده** (یا مالک ربات) «آزاد کردن رزرو» → Reply رزرو **حذف** شود
- [ ] بعد از **۱ ساعت** (یا Cron) رزرو آزاد + Reply حذف
- [ ] فروش از حالت رزرو → Reply رزرو حذف + Reply «فروخته شد»

## فروش و کانال
- [ ] Reply «فروخته شد» روی پست
- [ ] بعد از **۴۸ ساعت** + Cron: Reply فروش و پست اصلی حذف؛ رکورد `sold` در DB بماند

## فروش ویژه ۶۰ روز
- [ ] خط ۵۹ روزه → فروش ویژه **نشود**
- [ ] خط ۶۰+ روز → **۴٪** + Reply «فروش ویژه» + **یک‌بار**
- [ ] ثبت مجدد → شمارنده ۶۰ روز از صفر

## فاکتور و مشتری
- [ ] فاکتور نقدی + اقساطی + PDF
- [ ] `/customer کد_ملی` → **سوابق خرید مشتری** (چند فاکتور)
